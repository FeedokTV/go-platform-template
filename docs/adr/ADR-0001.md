# ADR-0001: Hexagonal over full Clean Architecture

Context:  This template should teach/prepare structure. Full clean architecture requires four layers with many boilerplate code (not for the template), simple layered don't shows the communication between realisation and core

Decision: Separate logic in core/adapter/platform and all dependencies point inward. Core don't use any particullar realisation (net/http or pgx) by **depguard** and checked by CI 

Consequences: Unfamiliar to Clean-by-the-book readers. The domain stays transport-naked, so every adapter maintains its own DTO's and mapping

At 10x scale: Another deliviry mechanism gives pay off. Multiple bounded contexts leads too modular monolith structure.

Status: Accepted
